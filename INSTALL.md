# Installation

## Method 1: VMware Workstation
This is the environment used to develop and test the project.

### Requirements
- VMware Workstation
- Nyarch ISO
- 3GB+ RAM
- 30GB+ storage

### Installation Steps

#### Downloading the Nyarch ISO
1. Go to https://nyarchlinux.moe/ and click "Download Now."
2. It'll bring you to Step 1 in the download section, which shows "GNOME" and "KDE Plasma". Click GNOME if you want a plug-and-play system. Click "KDE Plasma" if you want extensive customization.
3. You'll be shown Step 2 to pick the GPU variant. Click "Standard" if your GPU is AMD or Intel. Click "NVIDIA" if it's Nvidia (RTX).
4. Click the orange button that says "Download ISO" and let it download.

#### Downloading VMware Workstation
5. Go to https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion and click "Download Now."
6. Create or sign in to a Broadcom account: Go to Broadcom's support portal and register for a free account or log in.
7. Open My Downloads: Go to My Downloads (or Free Software Downloads) in your portal dashboard.
8. Choose your product: Select VMware Workstation Pro (for Windows or Linux) or VMware Fusion (for Mac). See Broadcom's guide on Download and Install VMware Fusion for Mac-specific setup steps.
9. Pick a release and accept terms: Expand the version and operating system you need, open and review the Terms and Conditions link first so the agreement checkbox unlocks, and check the box to agree.
10. Complete verification and download: Click the download button, fill out any required trade compliance or address verification prompts if requested, and save the installer.
11. Run the .exe file

#### Creating the virtual machine
12. Launch VMware.
13. Select "Create a New Virtual Machine".
14. Choose your guest operating system installer disc image (.iso file) and assign CPU, memory, and disk space. Nyarch needs a minimum of 3GB of RAM and 30GB of storage.
15. Find the virtual machine in the sidebar and click "Power on this virtual machine. It'll take a few minutes to load its files.
16. It'll ask for personalization information. Set what you want.
