# Nyarch
Nyarch is a Linux distro built directly on the Arch distro. Essentially, it’s Arch but beefed up with anime themed elements. It has custom apps like, most notably, Catgirl Downloader and Komikku. It’s supported by a small team, so it should be treated like a niche, novel OS.

# Objective
This project aims to turn Nyarch into a useful Linux distro by showcasing its strengths (catgirls) and configurations to create a useable service.
